# English

## What is Vibestack?

Vibestack is a universal AI operational layer designed to work with any AI coding runtime.

The model changes.
The context remains.

### Philosophy

- Model agnostic
- Token efficient
- Modular
- Portable
- Open source first

### Install

```bash
git clone https://github.com/your-user/vibestack.git
```

### Usage

Copy `.vibestack` into any project.

Load only the required context modules.

Example:

```txt
agents/backend.md
rules/backend.md
skills/debugging.md
```
